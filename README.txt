PixelLite Image Compressor — deployable static site

Files:
- index.html: homepage and browser-based image compressor
- compress-jpg/index.html, compress-png/index.html, compress-webp/index.html
- resize-image/index.html, reduce-image-size/index.html
- bulk-image-compressor/index.html, image-optimizer/index.html

Deploy:
1. Extract this ZIP.
2. Upload the files to a GitHub repository (keep folder structure).
3. In Cloudflare Pages, connect the repository.
4. For a plain static site, use build command `exit 0` and output directory `/` (repository root).
5. After deploy, replace `https://your-site.pages.dev/` in canonical links with your real Pages address.
